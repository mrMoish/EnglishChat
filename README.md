# EnglishChat 🇬🇧➡️🇷🇺

**EnglishChat** — это Telegram-бот для изучения английского языка, который помогает быстро переводить слова и фразы с английского на русский прямо в Telegram.

Проект создаётся с целью превратить обычный переводчик в удобного персонального помощника для изучения английского языка.

## ✨ Возможности

* 🇬🇧 Перевод английских слов и фраз на русский язык
* 💬 Работа непосредственно в Telegram
* ⚡ Быстрое получение перевода без необходимости открывать сторонние переводчики
* 📚 Возможность использовать переведённые слова для дальнейшего изучения

## 🚀 В планах

Цель EnglishChat — создать Telegram-бота, который объединяет **перевод, изучение и запоминание английских слов** в одном удобном инструменте.

Вместо того чтобы просто показывать перевод незнакомого слова, бот в будущем сможет помочь пользователю понять его значение, увидеть слово в контексте и постепенно запомнить его с помощью повторений.


Планируемые возможности:

* 🧠 Запоминание новых слов
* 📝 Повторение изученных слов
* 📖 Изучение слов в контексте
* 💬 Примеры использования слов в предложениях
* 🔄 Повторение слов через определённые промежутки времени
* 📊 Отслеживание прогресса изучения английского языка

## ⚙️ Installation

Клонируйте репозиторий:

```bash
git clone https://github.com/mrMoish/EnglishChat.git
cd EnglishChat
```

Создайте виртуальное окружение:

```bash
python3 -m venv venv
```

Активируйте его:

### macOS / Linux

```bash
source venv/bin/activate
```

### Windows

```bash
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## 🔐 Environment Variables

Создайте файл `.env` и добавьте необходимые переменные окружения:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
OPENROUTER_API_KEY=api_key
```

> Никогда не публикуйте токены и секретные ключи в репозитории.

## ▶️ Running the Bot

Запустите приложение:

```bash
python server.py
```

После запуска найдите своего Telegram-бота и отправьте ему английское слово или фразу.

Бот обработает сообщение и вернёт перевод на русский язык.
